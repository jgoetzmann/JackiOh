## BUILD §5's coverage floor: it was passing while measuring nothing

`pnpm test:coverage` reported `All files | 0 | 0 | 0 | 0` and `Lines: Unknown% ( 0/0 )`, and exited
0. With `projects`, coverage resolves its `include` globs against each **project's** root rather than
the repo root, so `packages/engine/src/**` matched nothing from inside `packages/engine`, where the
same files are `src/...`. A threshold over zero files passes — so the floor has been green since it
was written, with no code behind it. Same shape as `01_schema_invariants.sql`'s CHECK 12 passing as
superuser with RLS bypassed, and as `prompts.ts` looking healthy because a test registered
production's work handler on its behalf: **a gate that cannot fail is worse than no gate.**

Fixed (globs project-relative, scope moved to the command, which runs the two projects BUILD §4
names). Measured:
